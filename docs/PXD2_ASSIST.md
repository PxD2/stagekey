# PxD2 — grounding the firm on a real stack

StageKey exists so PxD2 is not a pack of private records with no public joint.

The joint is a stack other companies already operate:

- Adversal watches long video.
- StageKey prints plates.
- A local or hosted agent plans the farm card.
- The company pack (Mesh-Brain, ASTROCOM, Mulberry) stays the lab seed.

That is how the firm has footing in the real world before close: interoperable desks, inbound from a vendor who found the repo, a printer anyone can run.

Adversal is not described as an investor anywhere in this project.
